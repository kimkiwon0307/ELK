# ELK

## 1장 로그의 기본

### 로그(Log)란 무엇인가?
1. 로그는 시스템이나 애플리케이션에서 발생한 사건을 기록한 데이터이다.
2. Log : 기록된 데이터
3. Logging : 로그를 생성하고 기록하는 행위

### 로그가 필요한 이유
1. 장애 발생 시 원인을 추적하기 위해서이다.

### 로그의 주요 사용 목적
1. 장애 분석
2. 운영 확인
3. 보안 감사
4. 요청 추적
5. 성능 분석

### 로그와 모니터링은 어떻게 다를까?
1. Prometheus는 서버와 애플리케이션의 상태를 수치로 관찰한다.
2. ELK는 수집된 로그를 통해 구체적인 사건을 검색하고 분석하는 데 사용한다.

### 실무에서 활용
1. Grafana에서 장애 알림 발생
2. Prometheus 메트릭 확인
3. Kibana에서 로그 검색
4. 원인 조사 및 조치

### 로그가 기록하는 것들
1. 좋은 로그란 장애가 발생했을 때 문제를 분석하는 데 필요한 정보를 담고 있는 로그이다.

### 로그에 기록하면 좋은 핵심 정보 8가지
1. 발생시간
2. 로그 심각도
3. 발생 서비스
4. 요청 식별자
5. HTTP 요청 방식
6. 요청 경로
7. HTTP 응답 상태
8. 발생 사건 설명

### 로그에 남기면 안 되는 정보
1. 비밀번호,
2. Access Token, Refresh Token
3. 주민등록번호
4. 신용카드 정보
5. 세션 쿠키나 API Key

### 로그는 언제 남겨야 할까?
1. 애플리케이션 시작
2. 중요한 요청 수신
3. 주요 작업 완료
4. 예상 가능한 문제
5. 외부 시스템 오류
6. 비정상 종료
