
# ELK 프로젝트 학습

## 1장 2교시. 로그 수집·처리·저장·검색의 동작 원리

### 1. ELK 로그 처리 흐름

```text
Spring Boot
    ↓ 로그 파일 생성
Filebeat
    ↓ 로그 파일 읽기 및 전송
Logstash
    ↓ 로그 수신 및 가공
Elasticsearch
    ↓ 로그 색인 및 저장
Kibana
    ↓ 로그 조회 및 시각화
운영 엔지니어
```

**중요**
- 로그 수집 흐름: Spring Boot → Filebeat → Logstash → Elasticsearch
- 로그 검색 흐름: Kibana → Elasticsearch → Kibana
- Kibana는 Elasticsearch에 검색 요청을 보내 결과를 표시한다.

---

### 2. Filebeat — 로그 수집

Filebeat는 서버의 로그 파일을 읽어 Logstash 또는 Elasticsearch로 전송하는 수집기다.

**주요 구성요소**

| 구성요소 | 역할 |
|---|---|
| Input | 수집할 로그 파일 탐색 및 관리 |
| Harvester | 실제 로그 파일을 열어 데이터 읽기 |
| Registry | 파일 식별 정보와 읽기 위치(offset) 등의 상태 관리 |

**Registry가 필요한 이유**

Filebeat가 재시작되더라도 저장된 상태 정보를 이용해 로그 수집을 이어갈 수 있기 때문이다.

단, Registry가 있다고 모든 로그 중복이나 유실이 방지되는 것은 아니다.

**장애 점검**
- 로그 파일 경로가 올바른가?
- 파일 읽기 권한이 있는가?
- 새로운 로그가 발생하는가?
- Logstash 연결이 정상인가?

---

### 3. Logstash — 로그 가공

Logstash는 로그를 수신하고 필요한 형태로 가공한 뒤 다른 시스템으로 전달한다.

**기본 구조**

```text
Input → Filter → Output
```

| 단계 | 역할 |
|---|---|
| Input | 로그 수신 |
| Filter | 데이터 파싱 및 가공 |
| Output | Elasticsearch 등으로 전송 |

Filter는 필요에 따라 생략할 수 있다.

**로그 가공 예시**

가공 전:

```text
10:00:15 ERROR Database connection failed
```

가공 후:

```json
{
  "time": "10:00:15",
  "level": "ERROR",
  "message": "Database connection failed"
}
```

문자열을 시간, 로그 레벨, 메시지 등으로 구분하여 검색과 분석을 쉽게 만든다.

주요 필터:
- grok: 문자열에서 필요한 필드 추출
- date: 날짜 및 시간 파싱
- mutate: 필드 추가·수정·삭제 등

---

### 4. Elasticsearch — 로그 색인·저장·검색

Elasticsearch는 로그 데이터를 색인하고 저장하여 빠르게 검색할 수 있도록 하는 검색·분석 엔진이다.

**핵심 개념**

| 개념 | 의미 |
|---|---|
| Document | 하나의 JSON 데이터 기록 |
| Field | Document 내부의 개별 항목 |
| Index | 관련 Document들을 관리하는 논리적 단위 |
| Indexing | 데이터를 검색할 수 있도록 색인하는 과정 |

예시 Document:

```json
{
  "level": "ERROR",
  "service": "spring-app",
  "message": "Database connection failed"
}
```

- Document: JSON 데이터 전체
- Field: level, service, message
- Index: 이러한 Document들을 모아 관리하는 단위

**중요: Logstash와 Elasticsearch의 차이**

- Logstash = 로그 수신 및 가공
- Elasticsearch = 로그 색인·저장·검색

참고로 Elasticsearch도 Ingest Pipeline을 통해 데이터를 가공할 수 있지만, 이번 프로젝트에서는 Logstash가 주요 가공 역할을 담당한다.

---

### 5. Kibana — 로그 검색 및 시각화

Kibana는 Elasticsearch에 저장된 데이터를 조회하고 시각화하는 웹 인터페이스다.

주요 기능:
- Discover: 로그 검색 및 조회
- Data View: 조회할 인덱스 또는 데이터 스트림 지정
- Dashboard: 로그 분석 결과 시각화
- 시간 필터: 특정 시간대의 로그 조회

**주의**

Kibana에서 로그가 검색되지 않는다고 반드시 Filebeat에 문제가 있는 것은 아니다.

Elasticsearch 저장 상태, Data View, 시간 범위, 접근 권한 등도 확인해야 한다.

---

### 6. 리눅스 로그 분석 명령어

```bash
# ERROR 로그 검색
grep "ERROR" app.log

# 요청 ID 검색
grep "req-002" app.log

# 두 번째 필드 출력
awk '{print $2}' app.log

# 두 번째 필드가 ERROR인 로그 검색
awk '$2=="ERROR" {print $0}' app.log

# ERROR 로그의 시간과 요청 ID 출력
awk '$2=="ERROR" {print $1, $3}' app.log
```

위 awk 예시는 다음처럼 공백으로 구분된 로그 형식을 기준으로 한다.

```text
2026-10-22T10:00:02+09:00 ERROR req-002 DB failed
```

- $1 = 시간
- $2 = 로그 레벨
- $3 = 요청 ID
- $0 = 해당 줄 전체

이 실습은 Logstash의 데이터 가공 원리를 이해하기 위한 기초 실습이다.

### 7. 장애 대응 — Kibana에서 로그가 보이지 않을 때

다음 순서로 점검한다.

1. Spring Boot: 로그 파일이 실제로 생성되었는가?
2. Filebeat: 로그를 읽고 전송하고 있는가?
3. Logstash: 로그를 수신하고 정상 처리하는가?
4. Elasticsearch: 로그가 저장되고 검색되는가?
5. Kibana: Data View와 조회 시간 범위가 올바른가?

**핵심 원칙**

로그가 이동하는 경로를 이해하고, 어느 단계에서 문제가 발생했는지 원인을 좁혀 나간다.

---

### 8. 확인문제 및 정답

**Q1. Filebeat에서 실제 로그 파일을 읽는 구성요소는?**

정답: Harvester

**Q2. Filebeat Registry의 역할은?**

정답: 파일 식별 정보와 로그 읽기 위치 등의 상태 정보를 관리한다.

**Q3. Logstash 파이프라인의 기본 순서는?**

정답: Input → Filter → Output

**Q4. Elasticsearch에서 하나의 JSON 데이터 기록을 나타내는 용어는?**

정답: Document

**Q5. Kibana에서 ERROR 로그가 검색되지 않을 때 점검할 내용은?**

정답: Elasticsearch에 데이터가 저장되었는지, Kibana의 Data View와 조회 시간 범위가 올바른지 등을 확인한다.

**Q6. Spring Boot의 ERROR 로그가 Kibana에 표시되기까지의 과정은?**

정답:
1. Spring Boot가 ERROR 로그를 생성한다.
2. Filebeat가 로그 파일을 읽어 전송한다.
3. Logstash가 로그를 수신하고 가공한다.
4. Elasticsearch가 로그를 색인하고 저장한다.
5. Kibana가 Elasticsearch에 검색 요청을 보내 결과를 조회하고 시각화한다.

---

### 9. 핵심 암기 사항

| 기술 | 반드시 기억할 핵심 |
|---|---|
| Filebeat | Input / Harvester / Registry |
| Logstash | Input / Filter / Output |
| Elasticsearch | Document / Field / Index |
| Kibana | Discover / Data View / Dashboard |

**가장 중요한 한 문장**

Filebeat가 로그를 수집하고, Logstash가 가공하고, Elasticsearch가 색인·저장·검색하며, Kibana가 조회·시각화한다.
